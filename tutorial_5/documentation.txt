2.1 Why are the variables declared as private
Variables are declared as private to protect the data from unauthorized or accidental direct modification from outside the class and enforces encapsulation and data hiding.

2.2 What happens if the variables are declared public?
If the variables are declared public, any external class can directly access and modify their values without any restrictions or validation, which compromises data security and integrity.

2.3 Why do we use getters and setters?
We use getters and setters to provide controlled public access to private variables. Getters allow safe read-only retrieval of data, while setters allow controlled updates where validation rules can be applied before changing a value.
